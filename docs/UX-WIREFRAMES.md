# Mobile workflow wireframes

Each column below reads from top to bottom. Text and amounts are representative sample data.

## Home and quick add

| Home | Add expense |
|---|---|
| **Home** · November 2026 | **Add expense** · Close |
| **Spent this month** · **$684.30** | **Amount** · **$42.50** |
| Top categories · Groceries $218.20 · Dining $106.00 | Amount keypad or device keyboard |
| **Recent activity** · Groceries −$42.50 · View all | Category · Groceries |
| **Net worth** · $1,700.00 · View accounts | Description · Grocery store |
| Home · Activity · **+** · Accounts · More | Date · Today · Add note |
| | **Save expense** |

Home leads with spending for the selected month. Activity and Accounts links open their corresponding destinations. Add is reachable from any main screen. On successful save, return to the originating screen and announce the new expense. On failure, keep the form open with its values.

## Activity and editing

| Activity | Edit expense |
|---|---|
| **Activity** · Filters | Back to Activity · **Edit expense** |
| Search description or category | Amount · $42.50 |
| **Nov 24** | Category · Groceries |
| Grocery store · Groceries · **−$42.50** | Description · Grocery store |
| **Nov 23** | Date · Nov 24 |
| Coffee shop · Dining · **−$5.00** | Notes |
| Home · **Activity** · + · Accounts · More | **Save changes** · Delete expense |

Group expenses by calendar day in descending order. Open the edit form by selecting a row and preserve the list position and filters on return. Confirm deletion by naming the expense. If a search returns zero results, offer to clear the filters.
